## 🚀 Quick Setup (5 Minutes)

### Step 1: Get FREE Groq API Key

1. Go to: https://console.groq.com/
2. Click **"Sign Up"** (use Google/GitHub or email)
3. **No credit card required!** ✅
4. After signup, go to **"API Keys"**
5. Click **"Create API Key"**
6. Copy the key (starts with `gsk_`)

**That's it! No billing setup needed!**

---

### Step 2: Add to Render

1. Go to **Render Dashboard**
2. Select your **backend service**
3. Click **"Environment"** tab
4. Click **"Add Environment Variable"**

**Add this:**
```
Key: GROQ_API_KEY
Value: gsk_your-key-from-groq
```

5. Click **"Save Changes"**
6. Click **"Manual Deploy"**
7. Wait 2-3 minutes

---

## 🔧 Troubleshooting

### Issue: "Groq API key not configured"

**Check Render Environment:**
- Variable name is exactly `GROQ_API_KEY` (not GROQ_KEY or API_KEY)
- Value starts with `gsk_`
- No extra spaces before/after

### Issue: "Rate limit exceeded"

Groq free tier has:
- 30 requests/minute
- Just add small delay between requests if needed

### Issue: Still getting errors

1. Check Render logs for Groq initialization
2. Verify API key is active at https://console.groq.com/
3. Make sure you deployed latest code
